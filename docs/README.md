# ansible-practice 문서

이 디렉토리는 주제별 번호 체계로 문서를 정리합니다. 앞 번호는 학습과 운영 흐름을 나타내며, 90번대는 저장소 관리용 문서입니다.

## 문서 구조

- [01-basics](./01-basics/): Ansible 기본기 - Inventory, Playbook, 변수, Role 등 Ansible 기본 문서를 모읍니다.
- [02-examples](./02-examples/): Ansible 예제 - 실제 구성 예제와 재사용 가능한 샘플을 관리합니다.
- [03-checklists](./03-checklists/): 검토 체크리스트 - 배포 전 점검과 Role 리뷰 체크리스트를 모읍니다.
- [04-runbooks](./04-runbooks/): 운영 런북 - Playbook 실패와 Vault 운영 같은 대응 절차를 관리합니다.
- [90-standards](./90-standards/): 문서 작성 표준 - 저장소 문서 작성 규칙과 운영 기준을 관리합니다.
- [91-templates](./91-templates/): 문서 템플릿 - 반복해서 사용하는 문서 템플릿을 관리합니다.
- [99-agents](./99-agents/): AI 에이전트 가이드 - Ansible 문서와 Playbook 리뷰에 활용할 에이전트 역할 정의를 관리합니다.
